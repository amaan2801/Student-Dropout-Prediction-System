# Student Dropout Prediction System

## Overview

This project focuses on predicting student dropout risk using historical academic and behavioral data. The primary objective is to enable early intervention and improve student retention in educational institutions through data-driven insights.

---

## Key Features

* Comprehensive data preprocessing and feature engineering pipeline
* Supervised machine learning–based classification
* K-Fold cross-validation for reliable and unbiased model evaluation
* Command-line interface (CLI) for prediction and evaluation

---

## Tech Stack

* **Python**
* **Scikit-learn**
* **Pandas**, **NumPy**

---

## What I Built

Developed a production-ready machine learning pipeline capable of predicting student dropout risk with high accuracy. The system allows academic administrators to identify at-risk students early and take timely corrective actions.

---

## Impact

The model achieved **90%+ prediction accuracy** during internship use-case testing and significantly reduced manual monitoring and administrative effort.
